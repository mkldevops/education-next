# i18n (next-intl)

- Locales: fr, en (défaut: fr)
- Toujours ajouter les clés dans TOUS les fichiers de traduction (fr.json, en.json)
- Server Component: `const t = await getTranslations('namespace')`
- Client Component: `const t = useTranslations('namespace')`
- Navigation: utiliser `Link` et `redirect` depuis `@/i18n/routing`
- Routes préfixées par locale: `/fr/...`, `/en/...`
